---
name: Circuit Studio interface copy
description: Guidelines for keeping user-facing copy concise without hiding important decisions.
---

Keep normal interface copy short and action-focused. Do not narrate internal implementation or AI workflow. Put optional privacy and process details behind contextual help; keep essential safety warnings, current status, destructive-action scope, and whether changes are applied visible.

**Why:** The user prefers a focused interface where people learn the app through use instead of reading explanations about how it works.

**How to apply:** Before adding visible copy, ask whether it helps the user act, understand a current status, protect their work, or make an informed safety/privacy decision. If not, omit it or place it in an optional help disclosure.
